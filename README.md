# JAOLA OS

منصّةٌ تبني للمستخدم موقعاً أو تطبيقاً كاملاً من وصفٍ يكتبه بلغته — تفهم الطلب، تختار المسار، تبني، **ثمّ تحكم على ما بنته وتقول الحقيقة عن حكمها**.

## الخدمات

| الخدمة | الدور |
|---|---|
| **`backend/`** | قلبُ جولا: المولّد، الوكلاء، بوّابات الفهم والتحقّق والحكم |
| **`frontend/`** | واجهةُ المنصّة |
| **`travel-service/`** | جترافا — حجزُ طيرانٍ وفنادقَ وباقات ([تفصيلها](travel-service/CLAUDE.md)) |
| **`logo-service/`** | jalogo — توليدُ الشعارات |
| **`video-service/`** | توليدُ الفيديو |
| `workspace/` | مساحاتُ عمل المستخدمين المولَّدة — ليست شفرةَ المنصّة |

## التشغيل

```bash
# الاعتماديّاتُ الخمس (يُشغَّل تلقائيّاً عند بدء جلسة Claude Code)
.claude/hooks/session-start.sh

cd backend && npm start          # الخادم
cd backend && npm test           # ٢٠١٢ اختباراً (node --test، ليس Jest)
```

**المفاتيحُ تُضبَط في Render** — لا في المستودع. والخدمةُ تقول جاهزيّتَها بنفسها في سجلّ الإقلاع (`🚦 جاهزية الإطلاق التجاري`)، فلا تُطلَب قيمةُ مفتاحٍ في محادثة.

## المبدأ الحاكم

> **كلُّ ادّعاءٍ مؤيَّدٌ بقياس. وما لم يُصلَح يُقال ولا يُخفى.**

هذا ليس شعاراً بل ممارسةً مكتوبةً في المستودع: كلُّ تغييرٍ يُقاس قبله وبعده، ويُختبَر بالطفرة (تُكسَر الشفرةُ عمداً للتأكّد أنّ اختباراً يقع)، وما يُقاس ولا يُصلَح **يُسجَّل بأرقامه وسببِ تركه** بدل أن يُنسى أو يُدَّعى.

ولهذا في المستودع اختباراتُ **قياسٍ لا تدّعي إصلاحاً** — مثل `tests/goalFidelityMeasure.test.mjs` الذي يُثبّت فرضيّةً جُرِّبت **فسقطت**، كي لا يُعاد بناؤها بلا دليل.
