# دفعة جودة المنتج: سبعة مسارات

هذه الدفعة تفصل السلوك المقاس عن الجاهزية التشغيلية. نجاح فحص واجهة لا يثبت وجود خادم أو صلاحيات أدوار. تقرير `CLONE_READINESS_AUDIT.json` يفحص جميع الكلونات مع بصمة محتوى كل قالب، وتعيد CI إنشاءه وإرفاقه بكل تشغيل.

| المسار | التغيير | التحقق |
|---|---|---|
| الحجز | منطقة زمنية قابلة للإدارة، خدمات ومدد وأسعار، عدة موارد، منع تداخل المدد، استعادة برمز خاص | اختبارات التوقيت والتعارض وMongo، جلسة إدارة حقيقية، واجهة تنتظر تأكيد الخادم |
| المتجر | أسعار ومخزون وطلبات على الخادم، تحديث ذري يمنع البيع الزائد، منع تكرار الطلب، إلغاء يعيد المخزون مرة واحدة، تعديل المنتجات وتتبع العميل | سباق شراء، تلاعب سعر، تكرار، عزل العملاء والمشاريع، صلاحيات HTTP وواجهة فعلية |
| القوالب | تدقيق كل الكلونات، بيان جاهزية لكل قالب وللمشروع المولد، فصل أدوار الواجهة عن الصلاحيات الفعلية | فحص سلوكي لجميع القوالب العربية وفحص توطين المجموعة الإنجليزية |
| العربية | إعادة البناء تحتفظ بهوية المشروع؛ الإحالات المبهمة في تعديل أو حذف تسأل عن المرجع؛ غياب المشروع يسأل عن نوعه | أمثلة عربية ولهجية مع موجّه وهمي يتعمد اختيار شركة بناء |
| توزيع المهام | إعادة محاولة الوكيل المتعثر فقط بحد أقصى، حجب الاعتماديات الفاشلة، إصلاح ملفات الفحص الفاشلة، منع استبدال ملف لم يصل كاملاً | فشل مؤقت ودائم، تكرار هوية، سياق كامل، رفض ملفات مستبعدة |
| فحوص التطبيقات | إضافة اختبارات HTTP/DOM للمتجر، فحص جلسة الإدارة وإبطالها، تأكيد الحفظ من الخادم؛ تقرير الكلونات مرفق في CI | الاختبارات تعمل دون إرسال الكود إلى مزود ذكاء حي؛ Mongo محلي في CI |
| القياس | رموز منفصلة لكل مهمة متزامنة، زمن البناء P50/P95، أول محاولة عندما تتوفر أدلتها، نافذة زمن طلبات الحجز والمتجر، عرض في لوحة الصحة | اختبار عزل القياس المتزامن وحالات البيانات المفقودة |

## حدود مقصودة وقابلة للمراجعة

- الدفع عند الاستلام فقط. لا مزود دفع إلكتروني أو تسوية مالية أو إرسال إشعارات.
- استعادة الضيف برمز سري يمنح الوصول إلى طلباته أو حجوزاته. لا إثبات هوية بالبريد أو الهاتف. يجب حفظه قبل إغلاق الجلسة وعدم مشاركته.
- تُحفظ البيانات في Mongo؛ لا رجوع إلى بيانات محلية عند فشل خادم المتجر أو الحجز. التفعيل للمشاريع الجديدة/المعاد توليدها مع عنوان المنصة. المشاريع القديمة تحتاج إعادة توليد ونشر؛ النشر وحده لا يضيف واجهة جديدة إلى مشروع قديم.
- الحجز الافتراضي UTC حتى يختار المسؤول منطقته. أوقات فجوة التوقيت الصيفي مرفوضة؛ الساعة المتكررة عند العودة الشتوية تُحوّل إلى لحظة واحدة حتمية ولا تُعرض مرتين.
- الحد الحالي 2000 حجز أو طلب تاريخي لكل مشروع، و300 منتج، و20 مورداً و40 خدمة. عند الوصول يُرفض الإنشاء بوضوح؛ الأرشفة والترقيم والتوسع خارج هذه الدفعة.
- لا يعني تدقيق بقية القوالب ترقية جميعها إلى صلاحيات موظفين متعددة على الخادم. بيان الجاهزية يترك هذه النقطة غير مثبتة بدلاً من إعلانها مكتملة.
- نافذة البناء آخر 15 بناء؛ نافذة API آخر 100 طلب مشروع صالح للحجز والمتجر في العملية الحالية، بعد التحقق من هوية المشروع. ليست قياساً لكل APIs أو مراقبة موزعة. تكلفة الدولار غير معروفة وتبقى null؛ لا أسعار مخمّنة. رموز الاستدعاءات التي لم يرجع مزودها أرقاماً لا تدخل المجموع ويُعرض عددها عبر API.
- نسبة أول محاولة تخص الإصلاحات المقاسة في مسار إكمال الكلون؛ المراحل التي لا ترسل دليلاً تظل غير معروفة. إعادة محاولات الفرق لها إحصاء مستقل في نتيجة الفريق؛ ليست نقطة استئناف دائمة عبر إعادة تشغيل الخادم.
- اكتشاف ونشر fullstack/Next متعدد الخدمات لم يتغير في هذه الدفعة.

## تشغيل التحقق

`npm --prefix backend test`

`node --import ./backend/tests/helpers/mockProviders.mjs backend/scripts/auditClones.mjs`

`npm --prefix frontend run build`

CI تشغّل المجموعة مع قاعدة Mongo محلية حقيقية. بعد الدمج يُتحقق من نجاح جميع checks ثم نسخة Render الحية والصحة. لا يُعتدّ باختبارات محلية وحدها كدليل نشر.
